# meta/ — everything *about* this repository

The knowledge itself lives in `inbox/`, `sources/`, and `notes/`. This folder holds the rules and guidance.

- [`methodology/`](methodology/) — why the repo is shaped this way (CODE · PARA · Zettelkasten · LLM-Wiki, the
  lifecycle, and the metadata conventions).
- [`workflows/`](workflows/) — how to capture, preserve, synthesize, retrieve, and govern changes.
- [`templates/`](templates/) — the single copy of the note templates (also usable as Obsidian templates).
- [`obsidian.md`](obsidian.md) — optional Obsidian configuration for humans.
- [`mcp-setup.md`](mcp-setup.md) — optional Local REST API (with MCP) setup for agents, while Obsidian is open.
- [`security.md`](security.md) — security & operational considerations.

This is the deepest the directory tree goes — no further nesting beyond `methodology/`, `workflows/`, `templates/`.
Clarity over organizational abstraction.
