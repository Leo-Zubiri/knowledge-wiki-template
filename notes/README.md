# notes/ — the wiki (synthesized knowledge)

The knowledge layer: synthesized, own-words notes that answer questions, with citations into `sources/` and typed
links to each other. **This is what you read to answer a question.**

**Rules**
- Each note has frontmatter with `id`, `type`, `status`, `domain`, `created`, `updated` (see
  [`../meta/methodology/metadata.md`](../meta/methodology/metadata.md)); `summary` is strongly recommended.
- **Search before creating.** If a note covers the topic, **update it** rather than creating a duplicate.
- Write in your own words; **cite** the `sources/` entries a claim rests on.
- Link generously with typed, reason-annotated `related:` entries and `[[wikilinks]]`.
- **Trust ladder:** `unreviewed → proposed → reviewed → verified → deprecated`. Agents may set `unreviewed`/
  `proposed`; **only a human** sets `reviewed`/`verified`/`deprecated`. `deprecated` notes must point to a
  successor via `superseded-by`.

Organize by **frontmatter + links**, not deep folders. Use `index`/MOC notes as entry points if the domain grows.

See [`../meta/workflows/knowledge-synthesis.md`](../meta/workflows/knowledge-synthesis.md) and
[`../meta/workflows/retrieval.md`](../meta/workflows/retrieval.md).
